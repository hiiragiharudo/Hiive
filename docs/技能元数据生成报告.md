## 6. 方法与局限

- **产出覆盖层而非改写原文件**：原始 `SKILL.md` 字节不变，课题加工与原始语料可分离，便于消融与回滚。

- **只填补空字段**（`only_missing=True`）：绝不覆盖语料已声明的值——语料作者的声明优先级高于规则推断。

- **匹配范围限于正文前 60 行**：技能正文常在开头声明适用场景，后续数百行为操作细节；取全文会引入大量与技术栈无关的噪声词。

- **局限**：规则为关键词匹配，无上下文理解能力，对同义改写与技术栈隐含描述无能为力。后续可评估用 LLM 辅助推断，但须权衡可复现性与成本。
